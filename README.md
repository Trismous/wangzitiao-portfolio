# 王子滔 / AIGC 平面设计师作品集

静态作品集，使用原生 HTML / CSS / JavaScript 构建，可直接部署到 GitHub Pages。

## 本地预览

```powershell
cd E:\codex\测试\wangzitiao-portfolio
python -m http.server 4173
```

打开 `http://localhost:4173`。

## 发布到 GitHub Pages

1. 在 GitHub 新建公开仓库：`wangzitiao-portfolio`。
2. 将本目录内容提交到默认分支（通常是 `main`）。
3. 在仓库 **Settings → Pages** 中，将 **Source** 设为 **Deploy from a branch**，选择 `main` / `root`。
4. 发布地址将为：`https://<你的 GitHub 用户名>.github.io/wangzitiao-portfolio/`。

若仓库名改为 `<你的 GitHub 用户名>.github.io`，地址会是：`https://<你的 GitHub 用户名>.github.io/`。
